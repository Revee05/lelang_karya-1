## Ringkasan Folder `resources`

Folder `resources` pada proyek Laravel digunakan untuk menyimpan file sumber daya yang akan diproses sebelum digunakan di aplikasi. Berikut ringkasannya:

- **js/**  
  Berisi file JavaScript dan komponen Vue.js untuk interaktivitas frontend.

- **lang/**  
  Berisi file terjemahan (localization) untuk mendukung multi-bahasa aplikasi.

- **sass/**  
  Berisi file SASS/SCSS untuk styling aplikasi yang akan di-compile menjadi CSS.

- **views/**  
  Berisi file Blade template untuk membangun tampilan HTML aplikasi, termasuk halaman utama, admin, autentikasi, email, dan halaman publik.

Setelah diproses (compile), hasil dari folder ini akan ditempatkan di folder `public/` agar dapat diakses oleh pengguna aplikasi.
