# Dokumentasi Struktur Folder `lelang`

Folder `lelang` pada proyek ini merupakan folder khusus yang di dalamnya terdapat subfolder untuk penyimpanan file log aplikasi.

---

## Subfolder

### 1. **storage/**
  - **logs/**  
    Folder ini digunakan untuk menyimpan file log yang dihasilkan oleh aplikasi, seperti catatan error, aktivitas, atau proses tertentu yang terjadi selama aplikasi berjalan.

---

## Kesimpulan

Folder `lelang/storage/logs` berfungsi sebagai tempat penyimpanan log aplikasi yang berkaitan dengan fitur atau modul lelang.  
Log di sini dapat digunakan untuk debugging, audit, atau pemantauan aktivitas sistem yang spesifik pada modul lelang.
